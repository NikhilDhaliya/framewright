# 05 — UI Specification (Palmier Pro → Electron/TypeScript/React)

Source of truth: `palmier-pro/Sources/PalmierPro` (Swift 6.2, SwiftUI + AppKit). Every number in this file is taken from the Swift source; `file:line` citations are relative to `Sources/PalmierPro/`. Reference screenshot: `palmier-pro/assets/palmier-ui.png`.

Units: SwiftUI/AppKit points map 1:1 to CSS px at device-pixel-ratio 1. Let Electron/Chromium handle HiDPI scaling.

Conventions used in this document:
- `--pp-*` = CSS custom property defined in §1.
- `T.x.y` = `AppTheme.x.y` in Swift (e.g. `T.FontSize.sm` = 11 px).
- "SF:" = SF Symbol name; the Lucide equivalent is listed in §12.
- Every fixed UI string is localized in the Mac app (`L10n.string`). Keep the English strings in this spec verbatim as i18n keys.

---

## 0. Global look and feel

- **Monochrome UI.** The global tint is `T.Accent.primary` (near-white #ECECEC in dark, near-black #303030 in light), applied with `.tint(...)` on every window root (`Project/VideoProject.swift:474`, `Home/HomeView.swift:146`, `Settings/SettingsView.swift:236`). There is no blue system accent. Checkboxes, sliders, toggles, segmented controls and focus rings all use `--pp-accent`.
- **The default appearance is Dark.** Setting key `appAppearance` holds `system | light | dark`, and the default is `dark` (`UI/AppAppearance.swift:31`). On Linux, `system` follows `nativeTheme.shouldUseDarkColors`. Put `data-theme="dark|light"` on `<html>`.
- **UI font: the system font (SF Pro) with `.monospacedDigit()` for numbers.** On Linux, use **Inter** (it is bundled, see §12) with `font-feature-settings: "tnum"` wherever Swift uses `.monospacedDigit()`. For `design: .monospaced`, use **Geist Mono** (also bundled). For `design: .serif` (only the "T" Add Text glyph in the toolbar), use `Georgia, "Times New Roman", serif`.
- **Corner style.** Swift uses `RoundedRectangle(style: .continuous)` (a squircle). Plain CSS `border-radius` with the same radius is an acceptable match.
- **Window material.** Editor window: background `--pp-bg-base` at 70% opacity plus `.ultraThinMaterial` vibrancy (`Project/VideoProject.swift:481-483`). On Linux, use solid `--pp-bg-base`, because translucency is unreliable across compositors.
- **Sheets.** `appSheetBackground()` is `surface @ 0.80` over `.ultraThinMaterial` (`UI/AppSheetBackground.swift`). Linux: `background: color-mix(in srgb, var(--pp-bg-surface) 92%, transparent); backdrop-filter: blur(30px);`.
- **Hover feedback** is a rounded fill, never an outline (see `HoverHighlight`, §3.1). Hover/active transitions use `ease-out 150ms` (`T.Anim.hover`). Expand/collapse and layout transitions use `200ms` (`T.Anim.transition`).
- **Tooltips** come in two kinds:
  - Toolbar and preview controls use custom capsules drawn *below* the control, with no delay (`hoverTooltip`, §3.2).
  - Everything else uses the native tooltip (`.help`). `App/main.swift` sets `NSInitialToolTipDelay = 10` ms, so these also appear almost immediately. Do not rely on the HTML `title` attribute, whose delay is about 1 s. Render the same capsule tooltip (or a native-looking one) after about 10–50 ms.

### 5.3 Canvas
- **Fit:** the largest rect with the timeline aspect ratio (or a generating asset's requested ratio) that fits the area. It is then scaled by `canvasZoom`, centered, offset by `canvasOffset`, and clipped.
- **Letterbox:** the area outside the canvas shows `--pp-bg-surface`; it is not black. Video is drawn aspect-fit, and the video layer background is also the surface color.
- **Image tabs:** the image is drawn aspect-fit on **black**. While loading, show a small spinner. On failure, show `photo` (18 px, tertiary).
- **Zoom outline:** when zoom is below 100 %, the canvas gets a 1 px white @ 0.25 outline.
- **Zoom gesture:** ⌘ + wheel (Linux: **Ctrl + wheel**) zooms toward the cursor.
  - `factor = exp(Δy × s)`, where s = 0.005 for a trackpad (precise deltas) and 0.05 for a mouse wheel.
  - The zoom is clamped to **0.1×–8×**.
  - The offset is adjusted so the point under the cursor stays fixed.
  - Any zoom ≤ 1 resets the offset to zero.
  - Chromium delivers trackpad pinch as wheel events with `ctrlKey = true`, so pinch works through the same path.
- **Click to select** (timeline tab only; inactive during caption preview, crop and chroma sampling). Hit testing follows `PreviewHitTester`:
  1. Text clips are tested first; the topmost track wins, and the test respects rotated (tilted) corners.
  2. Then video and image clips, from track 0 (topmost) down; the first hit wins. The point is rotated into clip space and tested against the **cropped** rect.
  3. Clips with opacity ≤ 0.01 and clips on hidden tracks are skipped.
- **Overlay stack** (bottom to top):
  1. video
  2. image
  3. generation-failed panel
  4. generating overlay
  5. offline panel
  6. canvas guides
  7. exactly one of: chroma sampler / crop overlay / caption preview / transform overlay (in that priority)
  8. slip two-up (during a slip drag)

## 6. Timeline (`Timeline/`)

The Mac timeline is an AppKit `NSView` drawn with Core Graphics. **Recommendation:** render the ruler, track backgrounds, clips, lanes, markers and overlays on a single `<canvas>` (or a few stacked canvases) per timeline. ### 6.3 Ruler (`TimelineRuler.swift`)
- **Layout:** height 28, background `--pp-bg-surface`, no bottom border.
- **Major interval:** the first value in `[1,2,5,10,15,30,60,120,300,600,1200,1800,3600] × fps` frames whose width is ≥ 80 px (`80 / ppf` frames).
- **Minor subdivision count n:** the first value in `[20,10,5,4,2]` where `majorPx / n ≥ 6`. If none qualifies, there are no minor ticks. `framesPerMinor = floor(framesPerMajor / n)`.
- **Ticks** hang down from the **top** edge of the ruler:

  | Tick | Width | Color | Height |
  |---|---|---|---|
  | Minor | 0.5 px | `--pp-text-muted` @ 0.4 | 4 px |
  | Mid (when n is even) | 0.5 px | `--pp-text-muted` @ 0.4 | 6 px |
  | Major | 1 px | `--pp-text-muted` | 8 px |

- **Labels:** on every major tick, `HH:MM:SS:FF`. Font: 10 px tabular-digit system font, `--pp-text-tertiary`. Position: x = tickX + 4, baseline at rulerBottom − 2.
- **In/out range in the ruler:** fill `--pp-fill-soft` (text-primary @ 0.10), plus 1.5 px edge lines in `--pp-timecode` @ 0.80 spanning the ruler height.
- **Interactions:**

  | Gesture | Effect | Cursor |
  |---|---|---|
  | Click/drag | Scrubs the playhead: pauses playback, resumes on release, and clears the marker selection | `pointer` |
  | ⇧-drag | Creates an in/out range | `crosshair` |
  | Drag within ±8 px of a range edge | Moves that edge | `col-resize` |

- **Auto-scroll while scrubbing or dragging** (also used for clip drags):
  - Edge zone = min(56, 0.5 × width).
  - Step ramps from 4 to 28 px with how deep the pointer is in the zone.
  - Runs at 60 Hz.

### 6.5 Clip rendering (`ClipRenderer.swift`)
**Color source and size tiers**
- **Color** = `--pp-clip-<sourceClipType>`. Audio extracted from a video file keeps `sourceClipType = video`, so it draws **video-blue on an audio track**.
- **Foreground** (text, waveform, rubber band) = black or white, whichever has the higher WCAG contrast against the clip color. With the defaults: white on video, audio, image and text; black on animation and sequence.
- **Size tiers** (by on-screen clip width):

  | Width | What is drawn |
  |---|---|
  | < 8 px | Plain rect with no radius. Fill: error color if the media is missing, white if selected, otherwise the clip color. Nothing else. |
  | ≥ 8 px | Radius **4**, plus the 1 px border |
  | ≥ 32 px | Detail chrome (offset badge, keyframe markers), and the label when selected |
  | ≥ 48 px | Trim handles, fade knees, hover affordances |
  | ≥ 56 px | Label even when not selected |

**Layers, in draw order**
1. **Fill:** the clip color in the rounded rect.
2. **Label bar:** the top **16 px**. The body is the remaining h − 16 − 1 px. Text clips have no label bar.
3. **Video filmstrip** in the body:
   - Thumbnails are generated at max 120×68: one per second for sources under 10 s, otherwise one every 2 s.
   - Tile width = bodyHeight × the first thumbnail's aspect ratio. Tiles butt against each other from the clip's left edge.
   - Each tile shows the nearest thumbnail to the source time at the tile's left edge, accounting for trim and speed.
   - At most 200 tiles. Tiles not yet loaded show the plain fill.
4. **Image clips:** the single 120 px thumbnail, tiled the same way.
5. **Audio waveform:**
   - Envelope: 200 samples/s, peak dB normalized over −50…0 dB.
   - Draw one 1 px bar per pixel column, **bottom-anchored**: height = max(1, amp × (bodyH − 2)), bottom at body bottom − 1.
   - Color: foreground @ 0.70.
   - Volume and fades shift the amplitude by dB/50 per bar.
   - When speaker marking is on, bars use the speaker color @ 0.80.
   - **Dead air** (`markDeadAir`, default on): a full-height wash of `--pp-status-error` @ 0.35 over silent spans.
6. **Text clips:** the text itself, multi-line, inset (6, 2), 10 px medium, foreground color.
7. **Fades on non-audio clips:**
   - A wedge from the bottom outer corner to the knee.
   - The area above the curve is filled black @ 0.6, from the body top.
   - The curve is a 1.5 px stroke in foreground × (0.95 if controls are shown, else 0.75) × 0.7.
8. **Audio rubber band (volume line):**
   - 1.5 px, foreground @ 0.95 when controls are shown, else @ 0.75.
   - Y maps **+6 dB at the body top to −60 dB at the body bottom**.
   - Segment interpolation: smooth = 12-step smoothstep, hold = step, linear = straight.
   - Fade wedges above the line are filled black @ 0.35.
9. **Fade knees** (shown on hover or selection, width ≥ 48):
   - 7×7 squares at y = body top + 4, x clamped at least 13 px inside each edge.
   - Fill = the rubber-band line color, with a 0.5 px black @ 0.55 stroke.
   - Glyph inset 1.5 px: a black @ 0.55 triangle and a 1 px black @ 0.80 diagonal with round caps.
   - Hit area 14×14. Hover cursor `col-resize`.
10. **Volume keyframe diamonds** (selected clip only, width ≥ 48, lanes collapsed): 7 px, `--pp-timecode` fill, 0.5 px black @ 0.5 stroke. Hit area 14.
11. **Border:** 1 px `--pp-border-timeline-clip` (black in dark mode).
12. **Selected:** an additional 1.5 px `--pp-border-timeline-clip-selected` (white in dark mode).
13. **Generating:**
    - A white @ 0.08 wash, plus a DOM overlay clipped to radius 4.
    - The overlay is black @ 0.55 and contains "Generating…" (10 px semibold white) with gap 8 to a 60×3 bar, plus the shimmer (§3.7).
    - It is not hit-testable.
14. **Missing/offline media:** `--pp-status-error` @ 0.25 wash and a 1.5 px `--pp-status-error` @ 0.80 stroke.
15. **Label:**
    - Text is `"<name>  <duration>"` (two spaces). 10 px medium, foreground color, x inset 6, vertically centered in the 16 px bar, clipped.
    - Duration format: `HH:MM:SS:FF`, dropping the "HH:" part under 1 h.
    - Name = the first non-empty line of the asset name, the nested timeline name, or the text content.
16. **Multicam angle chip:**
    - A pill at (x + 4, y + 2): 9 px semibold, `--pp-multicam` fill, readable foreground @ 0.80, max width w − 8. The label starts after it.
    - When the label is hidden but the clip is ≥ 8 px wide, draw a 5 px red dot at (x + 2, y + 2) instead.
17. **Out-of-sync linked offset badge** (width ≥ 32):
    - Text "+N" / "−N" frames, in a pill: 10 px semibold white on #E54F4F, padding 1 × 4, min width 16.
    - Position: x = maxX − 4 − badgeW − 2, y = y + 2.
    - Hidden if it would start less than 6 px from the clip's left edge.
18. **Clip keyframe markers** (opacity / position / scale / rotation / crop / blur; width ≥ 32, lanes collapsed):
    - One 6 px diamond per unique keyframe frame, at y = bottom − 5.
    - Fill systemYellow @ 0.95, 0.5 px black @ 0.5 stroke.
19. **Beat ticks** on audio clips (`markBeats`, default on, body taller than 28 px). Ticks start at the body top:
    - Beats: 1×7 px, orange @ 0.7. Skip a beat if it is within 4 px of the previous tick.
    - Downbeats: 1×14 px, solid orange.
    - Every tick has a black @ 0.55 backing, 1 px wider on each side and 1 px taller.

### 6.6 Keyframe lanes
- **Opening:** the visual track's header diamond toggles the lanes. Lane state is view-local and **not persisted**. It resets when switching timelines and is pruned when no eligible clips remain.
- **Which lanes, in order:** Position, Scale, Rotation, Opacity, Blur, Crop. Only properties that some clip on the track supports get a lane. Audio tracks never get lanes; their volume keyframes are drawn on the clip itself.
- **Lane geometry:** each lane is **24 px** tall. Background `--pp-bg-base`, 1 px `--pp-border-subtle` bottom line.
- **Clip segment within a lane:**
  - Rect at y + 2, height 20.
  - Fill: clip color @ 0.25 if selected, @ 0.10 otherwise. Clips that cannot take the property use `--pp-text-muted` @ 0.04.
  - Only the vertical sides are stroked: 1.5 px `--pp-border-timeline-clip-selected` when selected, 0.5 px subtle otherwise.
- **Keyframes:** **8 px diamonds**, `--pp-timecode`, vertically centered. No interpolation curves are drawn. While lanes are open, the clip-level yellow markers and volume diamonds on that track are hidden.
- **Interactions:**
  - **Hit test:** ±7 px. On a tie, the selected clip wins.
  - **Click a diamond:** pauses playback, seeks to the keyframe, selects its clip, and starts a drag (`grabbing`).
  - **Drag snapping:** snaps to the clip start, the clip end − 1, and the keyframes of other properties. The drag is clamped strictly between the neighboring keyframes and live-seeks.
  - **Click empty lane space:** seeks there and selects the clip under the pointer. Cursor `pointer`; `grab` over a diamond.
  - **Right-click a diamond:** Linear / Smooth / Hold (checkmark on the current one; default Smooth) · ── · Delete Keyframe.
- **Lane header** (in the header column):
  - Background `--pp-bg-base`, 1 px subtle bottom line, **3 px `--pp-timecode` left strip**. Padding left 9, right 6, gap 2.
  - Property name: 9 px medium, secondary.
  - **Value fields** (timeline style): 36×18, value font 8 px, label 9 px, gap 4.
    - Position shows X and Y fields.
    - Crop shows an "Insets" button that opens a popover (§7.6).
    - Units: Opacity %, Rotation °, Scale % (pt for text), Blur px, Volume "dB".
  - Then the **KeyframeControlStrip** (§7.6).
  - On the last lane, the leading 31 px × bottom 6 px region passes clicks through so track resizing still works.

### 6.7 Snapping, marquee, gap selection, range
**Snapping**
- **Threshold:** **8 px** (divided by ppf to get frames).
- **Sticky:** once snapped, the snap holds until the pointer moves past 1.5 × the threshold. The playhead target also uses 1.5×. The nearest probe/target pair wins.
- **Targets:** the playhead, clip starts and ends (excluding clips being dragged), marker starts and ends, and beats (when `markBeats` is on).
- **Probes:** each dragged clip's start and end.
- Snapping is always on; there is no toggle. On the Mac it also gives haptic feedback, which Linux does not have.
- **Snap line:** **1 px systemYellow, dashed 4/4**, from the ruler bottom to the bottom of the view, z 90.

**Marquee** (drag on empty canvas)
- Look: 1 px dashed (3/3) border in text-primary @ 0.6, fill text-primary @ 0.1.
- It selects intersecting clips and markers, expanded to their link groups unless ⌥/Alt is held. ⇧ keeps the existing selection.

**Gap selection**
- Clicking empty track space that has a clip to its right selects the gap from the previous clip's end to that next clip's start.
- Look: fill text-primary @ 0.12, 1 px dashed (3/3) border in text-primary @ 0.9, inset like a clip (y + 2, h − 4).
- ⇧⌫ ripple-deletes the gap. Dragging more than 3 px clears the gap selection.

**In/out range** (half-open interval, start < end)
- Track area: filled with text-primary @ 0.06 from the ruler bottom down.
- Ruler: see §6.3.
- **I** and **O** set the start and end. **Esc** clears the range.

### 6.9 Playhead (`PlayheadOverlay.swift`)
- **Drawing:** `--pp-playhead`, 1 px line over the full viewport height, z 100. Its head is a downward triangle **8 wide × 8 tall** whose top sits flush with the viewport top, inside the ruler.

### 6.10 Zoom & scroll

| Input (Mac → Linux) | Behavior |
|---|---|
| Toolbar − / + | zoom ÷ / × 1.25 |
| Toolbar slider | log-mapped |
| ⌥ + wheel → **Alt + wheel** | zoom by `exp(deltaY × 0.04)`, anchored at the cursor |
| Pinch → **Ctrl + wheel** (Chromium pinch) | zoom by `1 + magnification × 1.5`, anchored at the cursor. Chromium pinch arrives as `ctrlKey` wheel events with small deltas; use `exp(−deltaY × 0.01)`. |

### 6.12 Master audio meter (`Audio/AudioMeterView.swift`)
- **Column:** 32 px wide, background `--pp-bg-base`, 1 px `--pp-border-primary` left border, padding 6 px vertical and 4 px horizontal.
- **Bars:** two 8 px bars (L, R), separated by a 1 px black line drawn at x = 7.5, plus a 2 px gap and a tick ruler.
- **Segments:** 1 px tall, separated by 1 px gaps. Unlit segments are black.

### 6.13 Drop behavior on the timeline
**Accepted drops**
- `palmier-asset://` payloads, optionally with a `#start-end` segment.
- `palmier-timeline://` payloads, which create a nested sequence clip.
- OS files, which are imported first and then placed.

**Placement**
- Drop into the **32 px zone above track 0** to insert a new track at index 0.
- Drop **between tracks** (±10 px) to insert a new track there.
- Drop **below the last track** to append a track.
- The feedback line is **2 px systemYellow** across the full width.
- Ghost clips use height 44.

**⌘/Ctrl held:** ripple insert (§6.5).

**Project settings check** (`EditorViewModel+ProjectSettings.swift:124-178`). This runs when a dropped set of assets contains a video:
- **Project settings never configured:** the project silently adopts the video's width and height. It also adopts the video's fps, but only if every timeline is empty.
- **Settings already configured, current timeline empty, and the fps or resolution differs:** the "Clip Settings Mismatch" sheet appears (§7.2) before the drop completes.
- **Timeline not empty:** the drop proceeds unchanged.

### 7.4 Row & control primitives
- **`InspectorRow`:**
  - Layout: HStack, gap 6, min height 22.

  - Every control applies changes live, without creating undo entries.

#### `ScrubbableNumberField` (most numeric fields)

**Defaults**

**Display text:** `sprintf(format, raw × mult) + suffix`.

**Drag:**
- Starts after |dx| > 3 px.
- `raw = startRaw + dx × sens / mult`.
- Modifiers: **⇧ = ×10** (coarse), **⌘ (Linux: Ctrl) = ×0.1** (fine).
- The value is clamped to the range, then any per-property adjustment (such as rotation snap) is applied.
- `onChange` fires live; `onCommit` fires on mouse-up.
- Lock the pointer during the drag with `requestPointerLock` so drags can be long.

**Click without dragging:** opens an inline edit.
- The field is prefilled with the number without its suffix (empty if the value is mixed), right-aligned, and focused.
- Enter or blur commits. Esc cancels.
- Parsing: trim → strip the suffix → replace "," with "." → parse as a finite number → divide by mult → clamp. Invalid input is ignored.

**Interaction lifecycle:** while an interaction is active, playback is paused and the frame is pinned. If the field unmounts mid-drag, the drag commits.

### 7.7 Adjust components

**`AdjustSlider`**
- **Size:** 10 px tall, full width.
- **Track:** 4 px capsule. It is either a gradient (temperature, tint, luma) or `--pp-bg-prominent` with a fill in `--pp-text-tertiary` from the **left edge** to the thumb. The fill does not start at the center, even for bipolar ranges.

**`ColorWheelControl`**
- VStack, gap 6: title (11 px medium, secondary), then the pad, then a master slider (luma gradient, 96 px wide).
- **Pad (96×96):**
  - **Disc:** a pre-rendered hue disc. Hue = atan2(y, x). Value v = 0.08 + 0.5·r^1.7. Saturation s = r^1.4. The rim gets a smoothstep over r 0.86→1 (`Compositing/ColorWheels.swift:36-50`). Render it once into a 160 px canvas.
  - **Overlays:** a hairline crosshair in white @ 0.08, clipped to the circle, and a 1 px subtle ring.
  - **Puck:** a 10 px white circle with a 1 px `--pp-bg-base` stroke and `--pp-shadow-sm`, positioned at (cx + x·r, cy − y·r).
  - **Interaction:** dragging starts after 2 px and is clamped to the unit disk. Double-click resets to (0, 0).

**`CurveEditorView`**
- VStack, gap 6:
  - Segmented control Y | R | G | B, full width.
  - A canvas, full width × **180**.
  - A hint line, "Drag to add or shape a point · double-click to remove" (9 px muted).
- **Canvas drawing:**
  - Histogram, only while playback is stopped: luma @ 0.35, plus R/G/B @ 0.35 with additive blending (`globalCompositeOperation = 'lighter'`).
  - Quarter grid lines in subtle @ 0.35, hairline weight.
  - Hairline subtle border.
  - Dashed (3/3) hairline diagonal.
  - The curve, sampled every 0.02 with **piecewise-linear** interpolation, drawn 1.5 px in the channel color:

    | Channel | Color |
    |---|---|
    | Y | text-secondary |
    | R | `--pp-curve-red` |
    | G | `--pp-curve-green` |
    | B | `--pp-curve-blue` |

  - Points as 9 px dots.
- **Interaction:**
  - A press within 15 px of a point grabs that point. Otherwise the press adds a new point. Dragging starts after 3 px.
  - The endpoints (x = 0 and 1) move vertically only. Interior points are x-clamped between their neighbors ± 0.001.
  - **Double-click removes the nearest interior point.** A curve always keeps at least 2 points.
  - The identity curve is stored as `[]`.

**`HueCurveEditorView`**
- **Mode picker:** segmented Hue | Sat | Luma, small, not full width.
- **Canvas:** 180 px tall, radius 6.
- **Background:** a 7-stop hue spectrum at opacity 0.35 (#FF3B30 → #F2D933 → #4DD959 → #33CCD9 → #4080F2 → #CC59E6 → #FF3B30).
- **Overlays:**
  - Hue histogram: fill white @ 0.15, top line white @ 0.8, 1 px.
  - 6 vertical grid lines.
  - A dashed horizontal midline at y = 0.5.
- **Curve:** cyclic (wraps 0↔1), sampled every 0.01, drawn 1.5 px in text-primary. Points are 9 px.
- **Default:** 6 points at x = k/6, y = 0.5. A curve counts as neutral when every point is within 1e-4 of 0.5.
- **Interaction:** the same as `CurveEditorView`.

### 10.2 Conflicts to resolve
- **⌘K** opens media search when the Media panel is focused, and is Split at Playhead everywhere else. Handle it in the renderer dispatcher *before* the menu accelerator: register the menu item with `registerAccelerator: false` and route the key yourself.
- **⌘A** selects all media when Media is focused. A plain **A** (no modifiers) is Select Forward when the Timeline is focused.
- **⌫** is context-dependent (media, markers, gap, clips), as listed above.
- Electron's default `role: 'selectAll'`, `role: 'copy'` and similar roles would hijack these keys. Use custom click handlers that forward to the renderer, except inside text inputs.

### 10.3 Key dispatcher rules (renderer)
1. Only the focused editor window handles keys.
2. If `document.activeElement` is an `input`, `textarea` or `[contenteditable]`, let every key through except the menu accelerators that use Ctrl.
3. Handle panel-scoped keys first (Media, then Preview / Timeline for Tab), then global keys, then menu items.
4. On mouse-down, call `blur()` on the active element unless the click landed in a text input. The Mac app does this with `resignStaleFocus`.

Linux implementation:
- Copy the folder unchanged, including the license files, into `resources/fonts/`.
- Load the fonts in **both** places they are needed:
  - **Renderer:** declare each with CSS `@font-face` and `font-display: block`, and call `document.fonts.load` before first paint.
  - **Native compositor / export pipeline:** register them with fontconfig. Either point `FONTCONFIG_FILE` at a private conf that adds `<dir>resources/fonts</dir>`, or pass the paths to the renderer process (FFmpeg drawtext / Skia).
- Build the "All fonts" list from `fc-list : family` and drop the bundled families from it.
- **Default text font:** the Mac defaults `TextStyle.fontName` to `"Helvetica"`, which most Linux systems lack. Resolve it through fontconfig, which usually substitutes Nimbus Sans or Liberation Sans. Alternatively, ship the default as Inter and map "Helvetica" to it when loading Mac projects.
- **UI fonts:** the Mac UI uses the system font, SF Pro. On Linux, use **Inter** for UI text, **Geist Mono** for `design: .monospaced`, and `font-variant-numeric: tabular-nums` wherever Swift uses `.monospacedDigit()`. Inter at the same px size renders slightly wider than SF Pro. Keep the sizes as specified and accept the small difference; do not scale the type.

### 12.3 SF Symbols → lucide-react

## 13. Linux adaptation checklist

1. **Modifier mapping.** ⌘ → Ctrl, ⌥ → Alt.
   - Keep ⇧ as Shift.
   - Move ⌘-wheel horizontal scroll to **Shift-wheel**, because Ctrl-wheel is pinch-zoom in Chromium.
   - Alt-drag may be grabbed by the window manager. Offer the alternative Ctrl+Shift-drag and mention it in the shortcuts pane.
2. **Vibrancy and Liquid Glass.**
   - Replace `.ultraThinMaterial` and `glassEffect` with solid tokens. For overlays, use `backdrop-filter: blur(24px)` on top of `color-mix(var(--pp-bg-surface) 85%, transparent)`.
   - Drop `scrollEdgeEffectStyle(.soft)`. Use a 16 px mask fade instead.
3. **Native pickers.** Replace the macOS color panel with a popover color picker. Replace the open/save panels with Electron `dialog`. `.palmier` is a **directory** package, so the open dialog must allow selecting directories, or filter by `project.json` inside one.
4. **Finder wording.** Change "Reveal in Finder" / "Show in Finder" to "Show in Folder" (`shell.showItemInFolder`). For Trash, use `shell.trashItem`.
5. **Keychain.** Use `safeStorage` / libsecret, with the same service and account names.
6. **Updates.** Replace Sparkle with electron-updater, or a GitHub releases check. Keep the Update badge and sidebar card UI.
7. **Notifications.** Use the Electron `Notification` API, gated by `io.palmier.pro.notifications.enabled`.
8. **System beep.** Use `shell.beep()`. It is used on invalid crop ratios, failed chroma samples, and refusing to unlock a multicam track.
9. **Haptics on snap.** Not available on Linux; drop them.
10. **Tooltips.** Show them after about 10 ms, as on the Mac (`NSInitialToolTipDelay = 10`).
11. **Panel minimums.** Enforce them in the split layout:
    - media ≥ 352
    - preview ≥ 400 × 320
    - inspector ≥ 300
    - timeline ≥ 100
    - agent 240–640
    - window ≥ 1032 × 600
12. **Persistence keys.** Keep all keys referenced in this document so Mac and Linux settings files map one-to-one:
    - `appAppearance`, `layoutPreset`
    - `agentPanelVisible`, `mediaPanelVisible`, `inspectorPanelVisible`
    - `rippleTimelineMarkers`, `markDeadAir`, `markBeats`
    - `timelineClipColor.*`
    - `samplesSectionExpanded`, `hasSeenWelcome`, `lastSeenVersion`
    - `appLanguage`
    - `io.palmier.pro.notifications.enabled`, `io.palmier.pro.analytics.enabled`, `io.palmier.pro.telemetry.enabled`, `io.palmier.pro.mcp.enabled`
    - `disabledModelIds`, `agentModel`, `agentReasoning.effort.*`
    - `searchIndexEnabled`, `generationPromptExtra`
    - split autosave keys (`editor.*`)
13. **Cloud-only UI to hide when no key or account exists.** This matches the Mac's own `isMisconfigured` mode:
    - Account pane and IdentityStrip
    - Sign-in rows
    - Sample Projects strip
    - credits chip and cost
    - Generate button
    - AI Edit tab and menus
    - "Organize with Agent"
    - Captions Cloud mode
    - FLUX Enhance
    - Feedback submission
    - Usage-data and crash-report toggles (unless you run your own endpoints)
