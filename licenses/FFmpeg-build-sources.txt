Sources of the libraries statically linked into the bundled FFmpeg
====================================================================================================

Framewright bundles the FFmpeg 7.0.2 static build by John Van Sickle (ffmpeg-7.0.2-amd64-static,
https://johnvansickle.com/ffmpeg/) as the ffmpeg and ffprobe executables, obtained through
ffmpeg-static (release b6.1.1). The build is licensed under the GNU GPL version 3. FFmpeg's own
source, ffmpeg-7.0.2.tar.xz, is attached to each Framewright release.

Both executables are statically linked: the libraries below are compiled into them. As GPLv3
section 6(d) allows, their source code is kept on the third-party servers linked below.
FFmpeg-build-README.txt in this folder is the build's own README.

How the versions were determined
- Entries without a note: the version is the one in FFmpeg-build-README.txt or embedded in the
  binary, and the link is to that exact release, git commit or Debian source package.
- "Inferred": the README does not list the library, or lists it inaccurately. The build was made on
  Debian 10 "buster" with gcc 8.3.0-6, so these libraries come from Debian 10 packages unless
  strings in the binary show a different version. For Debian revisions, the build machine is assumed to have
  the package updates that matched freetype 2.9.1-3+deb10u1 (listed in the README), which means
  Debian 10 updates up to about October 2020.
- "Approximate": the exact source could not be identified, so the entry links the closest source
  that can be justified.

Debian source packages are linked as .dsc files on snapshot.debian.org. A .dsc file names the
upstream tarball and the Debian changes, which are in the same directory. "dget -x <url>" (from
devscripts) downloads and unpacks all of them.
